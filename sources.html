Two additional studies, published in 2025

Human pancreatic islets: RNA, protein and metabolite features

Multiomics Analysis Reveals Insights into Potential Drivers of Pancreatic Islet Pathology in Type 2 Diabetes. ACS Omega, 2025. Public source tables. The protein table contains six donors; an exact RRID intersection retains three non-diabetic and three T2D donors across all three assays. Technical metabolomics injections are collapsed by the median of nonzero observations per donor; zero intensity is marked missing. Positive heavy:light protein ratios are log2 transformed. RNA is normalized to counts per million using all source count rows before ambiguous gene-label filtering, then transformed as log2(CPM+1). Untargeted metabolite features retain m/z and retention time and have no confirmed compound IDs.

This six-donor dataset illustrates methods and small-sample limitations; group differences can reflect age, sex, islet purity and other covariates. It does not establish a clinical classifier. Processed teaching data and exact source-file hashes · Data + R scripts.

Honeybee eggs: lipidomics and metabolomics

Chapman et al. Honey bee egg composition changes seasonally and after acute maternal virus infection. Scientific Reports, 2025. The public supplementary LC–MS tables and queen metadata yield 81 exactly matched queen identities (18 May, 63 June). Lipid-positive measurements form one view; positive and negative metabolite modes are combined into a second view. The teaching input preserves all 367 source lipids and 997 metabolite signals with their source row IDs and putative labels. Source tables flag all these features as passing CV<30%; positive intensities are log2 transformed, and zeros remain missing.

Queen identity links egg pools across assays. Collection month is an observational seasonal grouping, with collection date, beekeeper and environmental confounding. This is a two-view dataset; no transcriptome or proteome has been fabricated. Human gene/pathway annotations are not applied to honeybee measurements. Processed teaching data and source hashes · Data + R scripts. Public repository: Metabolomics Workbench ST003729.

Factor interpretation and figure exports

The interpretation page reports observed-pair Spearman correlations between factor scores and documented numeric or binary metadata. Binary encodings are named explicitly; four observed pairs are required. No association p values are claimed. The feature heatmap uses four top absolute-weight features per view for the selected factor; it is ordered by view and weight, not clustered. Correlations use the actual MOFA input and pairwise-complete observations. They are descriptive, can be confounded and do not imply physical interaction or causal effects.

SVG downloads preserve vector text and shapes. PNG downloads use a high-resolution render; Data downloads contain the plotted values. Background grids are removed from quantitative plots, with axes, units and legends retained. Network coordinates are illustrative layouts rather than measured axes. The R packages include a grid-free theme and an export_publication helper for editable PDF, optional SVG and 600-dpi PNG.

The classroom pipeline

  1. Check unique, exact matching cell-line IDs; align by ID.
  2. Filter features by missingness and nonzero variance. At the default30% threshold,919protein,1200RNA and225metabolite features remain.
  3. At the starting choices, select100 variable features per view and apply unit-variance scaling. The models do not use lineage labels.
  4. For principal component analysis (PCA) and distances only, fill remaining gaps with feature medians. Joint PCA divides each view by √selected feature count before concatenation.
  5. Multi-Omics Factor Analysis (MOFA) uses separate Gaussian views with gaps retained:2–6 selectable factors,100requested iterations,seed557,mofapy2 0.7.5. Internally prefix feature IDs by view so the same gene can occur in RNA and proteins.
  6. Welch tests use observed values with at least3per group. Skin minus Breast effects and Benjamini–Hochberg false discovery rate (BH FDR) q values are computed across all retained features within each view.

What the new figures show

Contribution circles show factor-wise reconstruction R² on observed, feature-centered entries. Contributions may overlap. Factor heatmaps show every cell line's learned scores. The view-agreement triangle reports descriptive Spearman correlations between within-view sample distances, with no hypothesis-test p values. RNA–protein gene examples begin with preselected teaching markers and then variable shared genes; pooled correlations can reflect lineage.

Lineage, subtype, batch and other covariates can all affect these exploratory patterns. The two-group tests do not adjust for those covariates. Factor signs and order can change across software environments. A shared factor alone does not establish causality.

Try factor count, centering and scaling

The factor-count experiment actually refits K2–6 on the same inputs and reports total in-sample reconstruction per view. Reference patterns are matched by absolute Spearman score correlation and one-to-one assignment, allowing signs and order to change. It does not select an optimal K. See the official MOFA FAQ.

Feature scaling divides each feature by its SD (unit variance), by √SD (Pareto), or leaves its scale unchanged. Centering subtracts feature means across the whole cohort; it does not center the Breast and Skin lineages separately. Whole-view scaling divides a complete molecular matrix by one global SD after optional centering. With center off, reconstruction uses an uncentered zero reference and includes mean levels. Its denominator differs from centered variation.

Reconstruction uses the actual post-centering/post-view-scaling input and its original missing-value mask. Total R² is computed from the sum of all factor predictions; factor-wise scores must not be added.

Feature networks

Each view contributes its own top-weight features to the network. Factor-link widths are scaled within view so weaker layers remain visible; actual weights and view contributions remain visible. The alternative co-variation mode computes observed, pairwise-complete Spearman correlations across molecular views, requires at least10 paired observations, applies the chosen absolute-correlation threshold, and shows at most100 edges. Neither mode is a physical-interaction or causal network.

GO, Reactome and metabolite pathways

The offline gene catalogs contain9134 GO biological-process terms from an explicit2024 org.Hs.eg.db/GO.db snapshot and1786 measured-overlap Reactome terms from release98. Metabolite memberships use153 KEGG reference maps with human counterparts. All source versions, download hashes and mapping decisions are included in the R kit.

Metabolites:84 unique name matches plus3 independently checked aliases;66 of these features have usable pathway memberships.113 ambiguous entries (including lipid sum compositions and isomer mixtures) and25 unmatched features are excluded from compound-level pathway assignments. Inspect every mapping decision.

One-sided hypergeometric over-representation analysis (ORA) uses the current model-view's features that have catalog membership as background, since those are eligible for weight ranking. Minimum background term size is3genes or2metabolites. BH correction includes every tested term, even zero-query overlaps, separately for each factor/view/catalog query. Displayed candidates are not automatically significant; no q<0.05 is stated plainly. Repeated interactive queries are exploratory, not a joint confirmatory FDR analysis.

The metabolite coverage view counts mapped compounds among all retained measured features. It has no p values and does not measure pathway activity. GO is a gene ontology; compound identities are used for metabolite pathway membership.

Independent classroom workspaces

Every page runs an independent calculation worker. Parameters, uploaded matrices and results stay in that page's memory; they are not written to a shared account or database. Run controls are locked while an analysis is active. Exports include a unique workspace ID and R replay code that reads the actual prepared matrices. Reloading clears unsaved results.

Local QA fits10real three-view MOFA models in independent browser workers with distinct seeds and100/200features per view, checks returned IDs/parameters/dimensions, and compares independent pages with different settings. This is not a field test on10student devices or classroom Wi-Fi. First loading requires internet for scientific libraries, so open the lab before class.
