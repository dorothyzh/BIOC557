CSV format and preparation

Use 6–300 samples in exactly two groups, with at least 3 samples per group. Every view must contain the same unique sample IDs. Each view can contain 4–5,000 unique features; all files together must be under 8 MB.

Omics table · samples in rows

sample_id,EPCAM,VIM,ACTB,...
s01,7.2,3.1,9.4,...
s02,6.8,3.5,9.1,...

Metadata table

sample_id,group,batch
s01,Control,Batch1
s02,Control,Batch1
s11,Treatment,Batch2

Features in rows are also accepted: put the feature ID in the first column and sample IDs in the remaining column headers. Sample order can differ between files. Blank cells, NA and NaN are treated as missing measurements.

Upload normalized RNA expression, such as log-transformed counts per million or a variance-stabilized matrix. Choose the scale already used in each file. Use matching gene IDs for protein and RNA when available; different ID systems remain separate. Functional enrichment uses the selected human or honeybee gene catalog.
