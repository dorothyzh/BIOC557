BIOC557 / DEFAULT R LAB

Honeybee head: protein and RNA

All demo data are included. Use the default settings. No code changes or manual path setup are needed.

Install R and RStudio once

Install R (4.3 or newer), then RStudio Desktop. These are separate downloads.

Make your first report

  1. Extract the entire ZIP into a folder on your computer.
  2. Double-click BIOC557.Rproj. This opens the project in RStudio.
  3. Open START_HERE.R in RStudio and click the Source button above the script.

The script installs missing packages automatically, runs the complete default analysis, and opens BIOC557_Default_Lab.html. The first run needs an internet connection and may take several minutes. Keep RStudio open while it finishes. No manual Python setup is required.

Run it again or read the code

Open BIOC557_Default_Lab.Rmd and click Knit. Each section contains a small R code chunk and a short explanation. The report fits the model again using the same data, settings and seed. It uses the demo files included with this package.

Your saved results

  • BIOC557_Default_Lab.html: the complete report.
  • outputs/figures/: every report figure as PNG, PDF and SVG.
  • outputs/: result tables, sample/gene alignment, analysis objects and software versions.

The RNA and protein model columns use the same gene IDs in the same order. The default is head tissue, MOFA with 5 factors, unit-variance scaling and 100 aligned genes per view.
